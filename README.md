Retail Sales ETL and Business Analysis Using MySQL

Project Overview

This project focuses on performing ETL operations and business analysis on a retail sales dataset using MySQL. The goal of this project is to clean, transform, and analyze sales data to generate meaningful business insights that support decision-making.

The dataset contains more than 7,500 sales records including customer information, product categories, sales, profit, discounts, cities, and order dates.

Objectives

* Perform ETL operations using SQL
* Clean and validate raw retail sales data
* Generate business reports using SQL queries
* Analyze sales, profit, customers, and product performance
* Identify high-performing and low-performing business areas
* Practice real-world Data Analyst reporting techniques

 Tools & Technologies Used

* MySQL
* SQL
* ETL Concepts
* Aggregate Functions
* CASE Statements
* Common Table Expressions (CTE)
* Window Functions

ETL Process Performed

Data Cleaning

* Renamed incorrect column names
* Checked missing values
* Identified duplicate records

Data Transformation

* Created profit margin calculations
* Generated customer segmentation
* Performed category-wise and city-wise aggregations

Data Loading

* Processed cleaned data for reporting and analysis

Business Analysis Performed

Sales Analysis

* Category-wise sales performance
* Top-selling products
* Monthly sales trends
* Yearly profit analysis

Customer Analysis

* Top customers by sales
* Customer segmentation using CASE statement

Profit Analysis

* Category-wise profit margin analysis
* Highest profit cities
* Poor-performing categories

Advanced SQL Analysis

* CTE-based profit analysis
* Above-average sales analysis
* Ranking categories using Window Functions

Key Business Insights

* Furniture category generated high sales but comparatively lower profit margins.
* Electronics category showed better profitability percentage.
* Monthly sales analysis helped identify business trend patterns.
* Customer segmentation identified premium customers based on purchase behavior.
